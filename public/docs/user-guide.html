How to refresh data, rebuild, and publish

Static copy for in-app help. Source: docs/user-guide.qmd (Quarto) in the repository.

This guide explains which Excel workbook defines the dataset, how the live site reads CSV, and how to publish updates on GitHub Pages.

Hosted deployment (PSC PVP on GitHub)

Published copies may use:

  • Source code: github.com/mag-services/psc-pvp-dashboard
  • Live site: mag-services.github.io/psc-pvp-dashboard/

How to update data on GitHub

The live site reads committed public/data/ministries_pvp.csv only (not Excel in the browser).

  1. Use workbook Ministries_PVP_Clean.xlsx, sheet data. Ensure CSV column headers match the required names below.
  2. Produce ministries_pvp.csv (UTF-8, comma-separated) — e.g. Excel Save As CSV from the data sheet.
  3. On GitHub, open public/data/ → replace ministries_pvp.csv (upload or edit) → commit to main.
  4. Open Actions and wait until the Pages deployment succeeds.
  5. Reload the live site with hard-refresh (Ctrl+F5).
Optional — CI from Excel: If Ministries_PVP_Clean.xlsx is committed at the repo root, GitHub Actions can run the export script on the server (Python + pandas). Otherwise, committing the updated CSV alone is enough.

Optional: store Excel on GitHub

You can commit Ministries_PVP_Clean.xlsx at the repo root for backup or so Actions can regenerate public/data/ministries_pvp.csv on each push (if that step is enabled in the workflow).

Folder layout (typical)

Dashboard = repo root (e.g. mag-services/psc-pvp-dashboard).

repo/
├── Ministries_PVP_Clean.xlsx
├── package.json
├── scripts/generate-data.py
├── public/data/ministries_pvp.csv
└── src/

Dashboard in a subfolder (nested monorepo).

repo/
├── Ministries_PVP_Clean.xlsx
├── psc-pvp-dashboard/
│   ├── package.json
│   ├── scripts/generate-data.py
│   └── public/data/ministries_pvp.csv

The export script looks for Ministries_PVP_Clean.xlsx beside the dashboard app first, then in the parent folder.

Which Excel file to update?

ItemDetail
File nameMinistries_PVP_Clean.xlsx
LocationRepo root next to package.json, or the parent folder if the app is nested.
WorksheetMust be exactly data (the export uses sheet_name="data").

Required columns (first row headers)

ColumnUse
MINISTRYBlank ministry rows are skipped.
DEPARTMENTDepartment
PRIORITY VACANT POSTSPost title in tables
POST NUMBERIdentifier
SALARY SCALECharts / labels
ANNUAL SALARYNumber (commas allowed)
RECRUITMENT STATUSEmpty / Unknown Status → Not Started

Renaming columns requires updating src/lib/data.ts.

How the app loads data

Static React + Vite app. It fetches ./data/ministries_pvp.csv at runtime — it does not read Excel in the browser. Routes: #/executive, #/ministry, #/recruitment.

Troubleshooting

SymptomCheck
Workbook missingPut Ministries_PVP_Clean.xlsx at repo root next to package.json or in the parent folder of the app.
Sheet errorWorksheet must be named data.
Rows missingMINISTRY must be non-empty.
Old data on PagesCommit/deploy latest CSV; rerun workflow.
