Priority vacant posts — web dashboard

Step-by-step update guide (you do not need to know coding or Git commands)

For ICT: source also in docs/user-guide.qmd if you rebuild with Quarto.

When you finish this guide once, updating the charts on the internet is the same routine every month: edit one Excel file on your computer, save it, click two buttons in GitHub Desktop, wait for the green tick online, refresh the dashboard website. Everything below assumes you never used GitHub before — only Windows (or Mac) and Excel.

Ways to reach this page

  • From the sidebar in the dashboard → Update guide
  • Open docs/user-guide.html in the project folder (only if IT gave you files directly)

Show me the dashboard website

ICT may give you one link everyone uses internally. If you publish to the example below, bookmark it.
mag-services.github.io/psc-pvp-dashboard/

Few words, plain English

GitHub
An online locker where ICT stores the dashboard project files. Nothing here replaces your normal Office use — GitHub Desktop is the door you use.
Repository (“repo”)
One GitHub folder that holds everything for this dashboard. You get one copy onto your laptop when you Clone (first-time steps).
Clone
Downloading that folder once so edits happen in the official copy ICT tracks.
Commit
Writes a labelled save-checkpoint (“I changed the vacancy numbers today”).
Push
Sends that checkpoint to GitHub so the internet can rebuild the dashboard.

Programs you install once

  • Excel (you already use it)
  • GitHub Desktop — free download: desktop.github.com
  • A GitHub account (email/password). Ask ICT to add your account so you can Push to your organisation’s repo if it is restricted.

First-time only · Get the project folder on your PC

Skip this blue section once your repository already appears in the left sidebar of GitHub Desktop.

A Open Clone from the menu bar

Start GitHub Desktop. Top menu → File → Clone repository…

BPaste ICT’s GitHub URL and pick a folder on your laptop

ICT gives you something like
github.com/org-name/psc-pvp-dashboard
Paste the URL tab or locate the repo list. Pick a Parent folder somewhere under This PC → Documents you can find easily — for example Documents\Work\GitHub\

C Confirm the dashboard repo is open

Left sidebar: select the dashboard repository name ICT told you.

Path memory aid: ICT may say the workbook lives inside psc-pvp-dashboard/public/data/. If you do not recognise these words, just follow Screenshots update-03 and update-04 — they show clicks and folders.

Every time you refresh the vacancy numbers

About 5 minutes after Push, ICT’s automatic build publishes the workbook; then you reload the dashboard site.

1 Open GitHub Desktop and choose this repository

Launch GitHub Desktop. In the left list, click your Priority vacant posts (or PSC PVP) repository.

2 Confirm you publish from the main branch

The top-middle dropdown should read Current branch · main (sometimes master). If ICT uses another branch they will inform you separately.

3 Open Windows File Explorer inside the cloned copy

Menu bar → Repository → Show in Explorer (Mac: Show in Finder). A Explorer window pops up showing the dashboard files.

4 Browse to folder public\data

Double-click folders until Explorer address bar resembles
...\psc-pvp-dashboard\public\data inside Downloads or Documents depending where you cloned. You seek one file:
ministries_pvp.xlsx

5 Open workbook in Excel

Double-click ministries_pvp.xlsx. Wait for Excel fully loaded.

6 Click worksheet tab data at spreadsheet bottom

You must edit the sheet named exactly data (capital/lowercase tolerated). Sheet tabs lie along Excel’s footer.

7 Stay on row 1 for column meaning — edit rows underneath

Never delete or rename the first header row. Change cells underneath (ministry fields, vacancy text, salaries, Recruitment status text). ICT may share a cheat-sheet for allowable status words.

8 Save (Ctrl + S), then close Excel

Use Ctrl + S keyboard shortcut quick-save. Completely close Excel afterward so Desktop sees the newest file snapshot.

Note: We reuse filename update-07 in two placeholders — ICT may rename to update-07a/update-07b if two separate images.

9 Return Desktop — workbook listed under Changes

Bring GitHub Desktop forward. Upper-left Changes tab should enumerate ministries_pvp.xlsx with +/- lines count.

If no file appears? You edited a different copy elsewhere. Always open through Show in Explorer from Step 3 so paths match.

10 Lower-left Summary box → type short description

For example:
“Updated vacancy postings — {month year}.” Two word minimum satisfies requirement.

11 Click blue Commit to main

Select it once — button greys/disables until next edit.

12 Publish local commit — press Push origin

If label reads Publish branch first-ever push ICT enabled for you instead, identical idea — confirms upload.

13 Browser → GitHub.com → Actions → wait green ✓ under latest run

Open your repository website (same URL cloned). Tab Actions row top. Wait circle finishes — green checkbox ≈ Published.

If red ✕ — STOP; forward screenshot ICT helpdesk rather than reloading dashboard.

14 Reload dashboard webpage

Open your internal dashboard URL new tab (example publish).

15 Deep refresh clears cache

Windows quick sequence Ctrl F5 one press while focus inside browser pane. Alternate: hold Ctrl click Refresh icon toolbar.

Compare totals against Excel totals — reconcile before reporting onward.

Privacy: Public GitHub repos make the workbook file publicly downloadable identical to screenshots if someone guesses filenames. Only commit information approved for widest audience ICT configured.

Recruitment status spellings (copy-paste safe)

  1. Unknown Status
  2. Vacant
  3. Advertisement
  4. Recruitment Process
  5. Awaits Commission Decision
  6. Occupied (Acting)
  7. Occupied (Contract)
  8. Filled
  9. Filled (Internship)
  10. Filled (Temporary)

Dashboard treats Vacant + Unknown Status together as “backlog” headline metrics.
